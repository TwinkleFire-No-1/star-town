## 执行记录

### T6.5.1 城镇地图镇子化重构（generateTownMap）
- **产出**：`client/src/game/map/TilesetManager.ts` — 地图重写为"真实镇子"：
  - **道路成网**：纵向双主街（x=8..9 / x=20..21）+ 横向北街(y=7)/南街(分两段避开民居)/广场南缘纵路，连接每栋建筑门口
  - **中央广场**：石砖铺装 + 喷泉 + 4长椅 + 4路灯（移入广场内）+ 花坛
  - **自然绿化**：建筑间错落树木/灌木/花丛/岩石，避免复制粘贴；边界树带第二列错落（灌木/花间隔）
  - **镇界**：四周树林带环绕，底部栅栏 + 中央入口大道 + 两侧路灯门柱 + 欢迎路牌
- **约束**：建筑位置与 TOWN_BUILDINGS / SCENE_PORTALS 保持一致（门口传送不失效）
- **耗时**：1.8h

### T6.5.2 建筑立体感增强（TownBuildingRenderer 重写）
- **产出**：`client/src/game/entities/TownBuildingRenderer.ts`：
  - **地面投影**：径向渐变椭圆（建筑"压"在地面）
  - **屋顶厚度**：屋顶主面下移形成粗边 + 屋脊高光 + 瓦片条纹 + 屋檐投影到墙面
  - **墙体明暗**：左受光右暗面渐变 + 墙脚接触阴影
  - **门洞纵深**：门洞内陷渐变 + 门楣横梁 + 台阶 + 门环
  - **窗台凸起**：玻璃上亮下暗渐变 + 窗台 + 阴影
  - **烟囱炊烟**：铁匠铺/民居烟囱冒烟
  - **集市**：中央门洞 + 货架移至两侧
  - **去重文字**：酒馆/集市/长老厅/矿洞/森林精灵内文字去除，统一由名称牌显示
- **耗时**：1.6h

### T6.5.3 室内场景确定性布局（generateInteriorMap 重写）
- **产出**：`client/src/game/scenes/SceneSystem.ts`：
  - 废弃随机撒家具（哈希种子），改为 8 个场景手工功能区布局：
    - 铁匠铺：熔炉(右)+铁砧(左)+货架+木桶；老巴克站铁砧旁
    - 药剂店：双书架+货架+坩埚+草药；艾拉站坩埚旁
    - 酒馆：连贯吧台(4格)+吧台后酒桶排+中央8桌用餐区+壁炉+挂毯
    - 集市：双货架+展桌+木箱堆+鱼桶；罗西站展桌后
    - 长老厅：书架+挂毯+中央长桌+地毯；塞拉斯/格罗姆站桌两侧
    - 民居：床+床头柜+衣柜+炉灶+木桌+地毯+盆栽
    - 森林：中央林间小路+树丛/灌木/岩石/花
    - 矿洞：矿脉+矿车+火把+睡袋+木箱
  - 门口内侧玄关留空，NPC站位避开家具
- **耗时**：1.8h

### T6.5.4 室内镜头自动缩放
- **产出**：`CameraController.setZoomLevel` + `GameScene.SCENE_ZOOM` 映射（室内12×10→2.5 / 酒馆14×11→2.2 / 森林→1.25 / 矿洞→1.6 / 城镇→1）
- **效果**：走进建筑后室内自动放大铺满屏幕，不再只占左上角
- **耗时**：0.6h

### T6.5.5 家具瓦片精致绘制
- **产出**：`TilesetManager.addTileDetails` 新增13种64px精致瓦片：木桌/木箱/木桶/铁砧/锻造炉/书架(三层彩色书)/柜台/炉灶(火+锅)/长椅/灌木/岩石/花园/路牌
- **效果**：室内家具从"噪点色块"变为可辨识的像素家具
- **耗时**：1.4h

### T6.5.6 场景切换链路修复（4个Bug）
- **修复1 家具下草地**：室内家具格子地面层未渲染，ensureGroundBelow 一律补草地 → 改为按相邻格子推断地板类型（室内补木地板/石地板）
- **修复2 NPC位置被覆盖**：后端 npc:move 广播城镇坐标覆盖室内NPC位置 → 非town场景忽略NPC移动同步
- **修复3 出生点与出口重叠**：所有室内场景 spawnPoint 距门口仅1格，玩家出生即 overlap 出口门自动回城 → spawnPoint 前移1格 + SCENE_PORTALS 同步
- **修复4 场景残留**：切换场景后城镇对象残留 → 确认 destroyAll / destroyNPC 完整清理
- **耗时**：1.6h

### T6.5.7 NPC脚下阴影
- **产出**：`NpcSpriteManager` 为每个NPC添加椭圆落地阴影（44×14、alpha 0.32），移动跟随、销毁清理
- **耗时**：0.4h

### T6.5.8 道路纹理优化
- **产出**：Ground_Path 重绘为"踩实土路"（碎石+脚印凹陷），不再像耕地垄沟
- **耗时**：0.4h
