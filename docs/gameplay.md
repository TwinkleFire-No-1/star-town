## 1. 游戏概述

### 故事背景

你是一名在星火小镇边缘苏醒的旅行者，失去了大部分记忆。铁匠老巴克发现了你，将你带回小镇。这座看似宁静的小镇之下，封印着一个古老的存在——堕落精灵法师阿拉密斯。三百年前，阿拉密斯试图用腐化之力吞噬整片森林，被精灵一族联合封印。

如今封印正在松动，一个神秘的暗影组织正试图彻底打破封印、释放阿拉密斯。你必须在五天的旅途中揭开真相、结交盟友、面对抉择，最终决定这个世界的命运。

### 游戏目标

- 探索星火小镇和周围的森林、遗迹、矿洞
- 与 12 个 NPC 建立关系，获取信息和帮助
- 完成主线任务，推进 5 章剧情
- 参与战斗，击败腐化生物和暗影组织
- 在终章做出最终选择，决定世界命运

## 2. 操控指南

### 基础移动

| 按键 | 功能 |
|------|------|
| **W / ↑** | 向上移动 |
| **S / ↓** | 向下移动 |
| **A / ←** | 向左移动 |
| **D / →** | 向右移动 |
| **W+A / ↑←** | 左上斜向移动（8方向） |
| **W+D / ↑→** | 右上斜向移动（8方向） |
| **S+A / ↓←** | 左下斜向移动（8方向） |
| **S+D / ↓→** | 右下斜向移动（8方向） |

> 斜向移动速度已归一化，不会比直线移动更快。

### NPC 交互

| 按键 | 功能 |
|------|------|
| **E** | 与附近 NPC 对话 / 交互 |

当你靠近 NPC 时，屏幕底部会显示交互提示 `[E] 与XXX对话`。按下 E 键即可开始对话。NPC 会用自然语言回复你，你可以自由输入想说的话。

### 对话框操作

| 操作 | 功能 |
|------|------|
| **输入文字** | 向 NPC 说出你想说的话 |
| **快捷动作** | 使用对话框下方的快捷按钮（送礼、告别、闲聊等） |

### 战斗操控

| 按键 | 功能 |
|------|------|
| **空格键** | 暂停/恢复战斗 |
| **鼠标点击** | 选择目标和技能 |
| **Q** | 战斗中触发角色行动 |

## 3. 小镇地图与区域

星火小镇及周边共有 9 大区域，每个区域都有独特的功能和隐藏要素：

| 区域 | 功能 | 关键 NPC | 隐藏要素 |
|------|------|----------|----------|
| **酒馆** | 休息、获取情报、购买饮食 | 玛格丽特 | 小镇信息交汇点，墙有耳朵 |
| **铁匠铺** | 购买武器防具、升级装备 | 老巴克 | 地下室藏有遗迹矿石样本 |
| **药草铺** | 购买药水、治疗、任务 | 艾拉 | 与精灵有秘密联络 |
| **矿洞** | 探索、战斗、获取矿石 | 铁砧 | 深处有低语和星火碎石 |
| **集市** | 交易、购买稀有物品 | 托比、罗西 | 托比见过星火碎片 |
| **面包房** | 购买食物、获取八卦 | 莉莉 | 小镇八卦网络核心 |
| **钟楼** | 占星、预言相关任务 | 西尔维娅 | 观星台有精灵联系 |
| **教堂** | 表面祈祷，暗藏阴谋 | 塞拉斯 | 地下室有暗影祭坛 |
| **隐居小屋** | 剧情关键、封印任务 | 格罗姆 | 最后的封印守护者 |

> 不同时间段 NPC 会在不同区域出现，参见昼夜系统。

## 4. NPC 图鉴

### 核心居民

#### 玛格丽特 — 酒馆老板娘
- **位置**：酒馆
- **性格**：热情好客、精明干练，对镇上每个人的秘密都了如指掌
- **商店**：啤酒、葡萄酒、特酿、烤肉、面包
- **秘密**：继承亡夫的酒馆，暗中收集信息等待丈夫归来
- **口头禅**：*"在酒馆里，没有什么是一杯酒解决不了的。"*
- **建议**：多和她聊天，能获得大量小镇情报。好感度提高后折扣很大。

#### 老巴克 — 铁匠
- **位置**：铁匠铺
- **性格**：沉默寡言但技艺精湛，脾气暴躁但对学徒极有耐心
- **商店**：木剑、铁剑、皮甲、铁甲
- **秘密**：手臂上有古老符文疤痕，知道精灵遗迹的秘密入口
- **口头禅**：*"铁不骗人，好就是好。"*
- **建议**：尽早购买装备。剧情推进到第二章后，他会透露遗迹入口。

#### 艾拉 — 草药师
- **位置**：药草铺
- **性格**：温柔但神秘，说话常带隐晦的比喻，能在风中听到植物的"低语"
- **商店**：草药、高级药水、魔法精华
- **秘密**：与精灵有秘密联络，知道星火的真正来历
- **口头禅**：*"风告诉我，今天有客人会来。"*
- **建议**：她提供主线关键任务"森林低语"和"草药师的秘密"，务必完成。

#### 铁砧 — 矿工头目
- **位置**：矿洞入口
- **性格**：粗犷豪爽，爱讲笑话，是矿工们的大哥
- **特殊**：**可雇佣为战斗队友**
- **秘密**：矿洞深处有低语声，他发现了散发微光的异常矿石
- **口头禅**：*"嘿！想听矿洞的故事吗？不，你不想。"*
- **建议**：好感度高时可雇佣加入战斗，是最强力的近战队友。

#### 托比 — 游商
- **位置**：集市
- **性格**：油嘴滑舌但讲义气，信息灵通
- **商店**：精灵石、稀有材料、异域饰品、情报
- **秘密**：在东方废墟中见过星火碎片
- **口头禅**：*"消息？我的消息比你的影子还快。"*
- **建议**：他卖的东西贵但有独家物品，可以买到其他地方买不到的稀有材料。

#### 莉莉 — 面包师
- **位置**：面包房
- **性格**：天真活泼，总是笑嘻嘻的，是小镇的"阳光"
- **商店**：面包、蛋糕、果酱面包
- **秘密**：小镇"八卦网络"的核心——每个来买面包的人都会聊上几句
- **口头禅**：*"嗯？你不知道吗？人人都知道呢。"*
- **建议**：多买面包，她会告诉你很多别人不知道的消息。

### 特殊居民

#### 西尔维娅 — 占星师
- **位置**：钟楼
- **性格**：神秘莫测、言辞隐晦，似乎能看到普通人看不见的东西
- **秘密**：能在梦中与精灵交流，星火坠落的预言是精灵托梦告诉她的
- **口头禅**：*"星辰已经告诉我了……"*
- **建议**：她的预言中隐藏着重要线索，注意仔细听她说的话。

#### 马库斯 — 守夜人
- **位置**：城墙
- **性格**：严肃认真、一丝不苟，对小镇安全有着近乎偏执的责任感
- **秘密**：曾在森林深处目击精灵遗迹入口的蓝光
- **口头禅**：*"我在林子里见过不干净的东西。"*
- **建议**：他掌握着森林异常的第一手情报，但需要好感度够高才会告诉你。

#### 罗西 — 花商
- **位置**：市场
- **性格**：乐观开朗、健谈热情，是小镇上最爱聊天的人
- **商店**：红玫瑰、月见草、向日葵、蓝莲种子、干花束
- **秘密**：花园深处的蓝莲是精灵遗物，月光下能发出微弱的治愈光芒
- **口头禅**：*"这朵花让我想到了你！"*
- **建议**：送花给其他 NPC 可以快速提升好感度。蓝莲种子是非常稀有的物品。

#### 小皮普 — 报信童
- **位置**：广场（到处跑）
- **性格**：机灵好动、好奇心旺盛，是小镇上跑得最快的人
- **秘密**：在森林边缘捡到了星火碎片，但以为只是普通的发光石头
- **口头禅**：*"我知道一个秘密！"*
- **建议**：他的"秘密"里可能藏着关键线索。给他糖果可以让他多说话。

### 剧情关键 NPC

#### 格罗姆 — 隐居术士
- **位置**：隐居小屋（北部密林）
- **性格**：古怪孤僻，说话艰涩难懂，对星火之力保持着数百年的执念
- **秘密**：最后的封印守护者，左臂已石化，活了两百余年
- **任务链**：封印的守护者 → 星火传承 → 最后的仪式
- **口头禅**：*"星火不灭，封印不破……但又能持续多久呢？"*
- **建议**：第三章核心 NPC，需要多次对话建立信任。他会告诉你封印的全部真相。

#### 塞拉斯 — 暗祭司
- **位置**：教堂
- **性格**：表面温和虔诚、乐于助人；实际上内心冷酷狂热、善于伪装
- **秘密**：暗影教派潜伏者，教堂地下有秘密祭坛
- **口头禅**：*"愿光明照耀你，我的孩子。"*
- **建议**：**终极 BOSS**。前期不要暴露对他教堂的怀疑，否则剧情会提前触发。

## 5. 主线剧情攻略

### 序章：星火初燃

你从昏迷中醒来，被铁匠老巴克救起。你需要了解小镇的基本情况，认识关键人物，并完成战斗训练。

| 任务 | 说明 | 关键提示 |
|------|------|----------|
| 苏醒 | 在老巴克的小屋醒来 | 对话了解基本操作 |
| 小镇初识 | 认识 3 位关键 NPC | 推荐先找玛格丽特、莉莉、艾拉 |
| 初试锋芒 | 完成战斗训练 | 练习暂停-行动的 RTwP 战斗节奏 |
| 森林异变 | 发现森林中的腐化迹象 | 前往森林边缘触发剧情 |

### 第一章：森林低语

深入低语森林，发现腐化正从森林核心向外蔓延。沿途遭遇被腐化的动物、变异植物和神秘遗迹。最终面对被腐化的森林守卫（BOSS 战）。

| 任务 | 说明 | 关键提示 |
|------|------|----------|
| 低语之路 | 进入森林，抵达第一个据点 | 带够药水，路上有腐化怪物 |
| 腐化之源 | 调查 3 处腐化节点 | 每个节点都有小型战斗 |
| 沉睡的遗迹 | 发现古代封印遗迹 | 注意收集精灵符文线索 |
| 守卫之战 | 面对 BOSS：被腐化的森林守卫 | BOSS 有三阶段，注意暂停调策略 |
| 封印修复 | 协助修复封印 | 修复是暂时的，剧情继续推进 |

### 第二章：深处的秘密

修复封印后得知真相——封印背后是堕落精灵法师阿拉密斯。深入古代遗迹寻找线索，揭开三年前大火的真相，与暗影组织交战。

| 任务 | 说明 | 关键提示 |
|------|------|----------|
| 封印之密 | 向关键 NPC 了解封印的真相 | 找老巴克和艾拉对话 |
| 古代遗迹 | 探索遗迹，寻找阿拉密斯的线索 | 遗迹中有谜题和陷阱 |
| 真相之火 | 揭开三年前大火的真相 | 大火不是意外——有人故意引燃 |
| 暗影来袭 | 与暗影组织交战 | 敌人使用暗影魔法，带抗暗影装备 |
| 日记残页 | 获取阿拉密斯的日记并解读 | 日记提到关键地点——精灵圣林 |

### 第三章：精灵的遗言

前往精灵圣林寻找生命之树。遇到最后的精灵后裔格罗姆，在他引导下发现最后封印。暗影组织发动总攻。

| 任务 | 说明 | 关键提示 |
|------|------|----------|
| 圣林之路 | 前往精灵圣林 | 需要通过格罗姆的信任测试 |
| 最后的精灵 | 与格罗姆建立信任 | 需要多次真诚对话 |
| 生命之树 | 在生命之树下发现最后封印 | 封印中残留着精灵一族的记忆 |
| 圣林之战 | 击退暗影组织的总攻 | 多波次战斗，格罗姆可加入队伍 |
| 法杖之钥 | 得知阿拉密斯法杖的秘密 | 法杖是封印的核心，也是解封的关键 |

### 终章：星火重燃

集齐法杖三段碎片，前往暗影之塔面对暗祭司塞拉斯。击败塞拉斯后，在生命之树前做出最终选择。

| 任务 | 说明 | 关键提示 |
|------|------|----------|
| 密室之匙 | 在小镇地下找到法杖第一段 | 地下密室有精灵防护法阵 |
| 巢穴之心 | 在腐化巢穴深处找到法杖第二段 | 需要击败腐化守护者 |
| 暗影之塔 | 前往暗影组织总部 | 塔内有多层战斗 |
| 宿命之战 | 击败暗祭司塞拉斯（终极 BOSS） | 塞拉斯三阶段，暗影魔法极强 |
| 星火抉择 | 在生命之树前做出最终选择 | 决定结局走向 |

### 三种结局

| 结局 | 选择 | 结果 | NPC 反应 |
|------|------|------|----------|
| **永恒封印** | 使用法杖加固封印 | 阿拉密斯永眠，世界恢复和平，但精灵之力逐渐消逝 | 格罗姆释然但悲伤，玛格丽特欣慰 |
| **灵魂救赎** | 说服阿拉密斯放下仇恨 | 阿拉密斯自愿消散，封印不再需要，暗影与精灵和解 | 格罗姆泪流满面，最温柔的结局 |
| **薪火终结** | 摧毁法杖 | 一切力量消散，代价沉重，包括格罗姆在内的精灵之力消失 | 壮烈但沉重的结局 |

## 6. 战斗系统

### RTwP（实时暂停）战斗

星火小镇采用 RTwP（Real-Time with Pause）战斗系统，类似经典 CRPG 的战术战斗：

1. **战斗实时进行**：敌我双方同时行动
2. **随时暂停**：按空格键暂停战斗，从容制定策略
3. **暂停中下达指令**：暂停时选择技能、目标、站位
4. **恢复后执行**：取消暂停后角色执行指令

### 敌人 AI 行为模式

| 行为模式 | 描述 | 应对策略 |
|----------|------|----------|
| **近战冲锋** | 直奔最近的敌人 | 用远程攻击优先击杀 |
| **远程射击** | 远距离攻击 | 靠近后贴身缠斗 |
| **法术施放** | 远距离施放魔法 | 打断或快速接近 |
| **治疗支援** | 治疗友方单位 | 优先击杀治疗者 |
| **逃跑** | HP 低时逃跑 | 留意逃跑方向，堵路 |

### BOSS 战

BOSS 拥有三阶段 AI，每个阶段行为模式不同：

| 阶段 | HP 范围 | 行为 | 建议 |
|------|---------|------|------|
| 第一阶段 | 100%-60% | 常规攻击模式 | 消耗 HP，观察攻击模式 |
| 第二阶段 | 60%-25% | 技能强化，召唤小怪 | 优先清理小怪，注意闪避 |
| 第三阶段 | 25%-0% | 狂暴模式，伤害大幅提升 | 使用药水和终极技能速战 |

### 队友系统

以下 NPC 可在好感度足够时加入战斗：

| 队友 | 加入条件 | 战斗定位 |
|------|----------|----------|
| 铁砧 | 好感度 >= 3 | 近战坦克，高防御 |
| 格罗姆 | 第三章剧情 | 远程法师，高伤害 |

## 7. 任务系统

### 任务类型

| 类型 | 说明 | 示例 |
|------|------|------|
| **主线** | 推进剧情的必做任务 | 序章"苏醒"、终章"星火抉择" |
| **支线** | 可选任务，丰富世界观 | "草药师的秘密" |
| **日常** | 可重复的小任务 | 送信、采集草药 |
| **涌现** | 由 NPC 社交网络动态生成 | NPC 之间传播消息后触发的新任务 |

### 任务状态

| 状态 | 说明 |
|------|------|
| 可接受 | 任务已解锁，等待接受 |
| 进行中 | 已接受，正在完成目标 |
| 可完成 | 所有目标已达成，可交付 |

## 11. 游戏技巧

### 新手建议

1. **先和玛格丽特聊天**：她是小镇信息枢纽，能告诉你很多有用的情报
2. **尽早购买装备**：木剑和皮甲是前期性价比最高的装备
3. **多和 NPC 对话**：AI NPC 记得你说过的话，积累好感度很重要
4. **注意时间**：某些 NPC 和事件只在特定时段出现
5. **存钱买药水**：战斗中药水是续命的关键

### 中期建议

1. **提升铁砧好感度**：让他加入队伍，战斗难度大幅降低
2. **探索矿洞**：深处有星火碎石，是后期剧情的关键道具
3. **和小皮普交朋友**：他知道的秘密比你想象的多
4. **收集精灵符文**：遗迹中的符文是解锁剧情的关键
5. **注意塞拉斯的行为**：22 点后教堂地下室有异动

### 后期建议

1. **准备终极战斗**：买最好的装备和大量药水
2. **与所有关键 NPC 对话**：获取最终的祝福和增益
3. **谨慎选择结局**：三种结局各有代价，没有完美答案
4. **格罗姆是关键**：在终章中，他对结局有重要影响
5. **备份存档**：如果你想体验三种不同结局

### 隐藏要素

- **蓝莲种子**：罗西的花园深处种着精灵蓝莲，月光下会发光
- **教堂地下室**：塞拉斯的秘密祭坛，需要夜晚 22 点后才能进入
- **铁匠铺地下室**：老巴克藏着的遗迹矿石样本
- **小皮普的树洞**：他在森林边缘藏了一块星火碎片
- **精灵符文**：散落在遗迹和矿洞中，集齐有特殊效果
